## 1. 引言与原有模型痛点分析
在前期版本的设计与仿真中，机械腿在模拟高频换弓与高速往复运动时，电机选型指标曾出现数值突变和玩具级缩水的两极分化现象。经过团队深入排查，定位了原模型的三个致命硬伤：
1. **数值微分爆表**：原代码对离散位置数据直接采用前向差分（`diff`），在换向等不连续点处极易放大高频数值噪声，导致加速度产生几千 $rad/s^2$ 的虚拟尖峰。
2. **动力学模型过度简化**：原模型将大腿（L1）与小腿（L2）拆解为两个独立的单摆模型，完全忽略了双连杆机构在高速摆动下的惯性耦合项与哥氏力/离心力（Coriolis）效应。
3. **滑轨载荷缺乏物理边界**：原选型未考虑腿部高速摆动对基座滑块产生的动态反作用力，缺乏严谨的力学支撑。

针对上述痛点，本阶段对系统进行了彻底的运动学与动力学重构。

## 2. 核心算法修复与优化方案

### 2.1 运动学平滑处理
* **滑轨部分**：摒弃离散差分，推导并写出了滑轨五次多项式运动轨迹的**解析解速度（一阶导）与加速度（二阶导）**，从源头保证了输入的绝对平滑。
* **关节部分**：引入 **Savitzky-Golay（SG）平滑滤波器** 对角度序列进行预处理，并采用具备二阶几何精度的**中心差分法（`gradient`）**代替前向差分，彻底干掉了数值尖峰。

### 2.2 2-DOF 拉格朗日全耦合动力学建模
基于拉格朗日方程，推导了严格的双连杆耦合动力学方程：
$$\tau = M(\theta)\ddot{\theta} + H(\theta, \dot{\theta}) + G(\theta) + J^T F_{ext}$$
完全补全了**惯性耦合项**（$M_{12}\cdot\alpha_2$）、**哥氏力/离心力项**（含有 $\dot{\theta}^2$ 的 $h$ 项），实现了大小腿之间动态撕扯效应的精确模拟。

### 2.3 基于牛顿-欧拉（Newton-Euler）法的基座反力反推
通过各刚体质心的动态加速度，利用牛顿第二定律严格反推了腿部运动对滑块产生的动态水平反力（$F_{base\_x}$）与垂向冲击力（$F_{base\_y}$），为传动与导轨选型提供了真实边界。

## 4. 结论与后续硬件优化建议
1. **电机选型方案确立**：大腿电机应选择**额定扭矩 $\ge 1.0 \text{ N·m}$、但具备 2.0 倍以上瞬时过载能力（即过载扭矩 $\ge 2.0 \text{ N·m}$）**的紧凑型高密度伺服电机或高阶步进电机；小腿电机可按额定 0.25 N·m 规格进行轻量化选型。
2. **丝杠选型警示与优化**：仿真结果显示丝杠峰值转速逼近 10000 RPM，即使在 95% 分位数下也高达 4429 RPM，这极易引发丝杠高频共振与噪音。**下一阶段建议将导程从 25mm 放大至 30~40mm，或将传动机构更改为同步带传动**，以强行降下驱动轴的物理转速。
3. **导轨布局推荐**：偏载力矩均在安全范围内 ($\le 1.17 \text{ N·m}$)，为保证高频换弓时的系统刚度与抗倾覆能力，建议采用**高刚性单导轨 + 加长型双滑块**的物理结构布局。
