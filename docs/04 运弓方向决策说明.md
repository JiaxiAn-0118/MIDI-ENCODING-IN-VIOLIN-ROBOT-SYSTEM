# 运弓方向决策说明

> 这份文档说明当前版本的运弓方向决策逻辑，重点是“真实小提琴习惯优先”，而不是简单的“同弦连奏默认保向”。

本文档更新的核心目的：
- 修正简单 legato 规则导致的误判；
- 解决长音、弱起、换弦、短句呼吸等场景下的方向不自然问题；
- 让机械臂的运弓既满足演奏发音要求，又尽量符合音乐的呼吸感和弓位控制；
- 说明当前版本中“slur/连弓”仍没有接入视觉识谱模块，因此暂时只能依靠 MIDI 隐式判断或显式输入接口。

---

## 1. 当前版本的基本原则

当前决策器原则上遵循下面的优先级：

1. 显式 slur / 连弓优先
   - 如果上游视觉识谱模块或显式输入告诉当前音与前一音属于 slur，则保持同一弓向。
   - 但即使是 slur，也必须满足“没有长延音/长同向积压/弓位越界”的前提。

2. 长延音必须换向
   - 当当前或上一音为长音时，不再简单保留上一方向。
   - 这是为了避免长音在同一方向上持续过久，造成弓位压迫、发音发硬、机械动作不自然。

3. 弱起和短句需要呼吸感
   - 开头弱起、乐句边界、短句收口时，不能机械地一直保持同一方向。
   - 例如在曲首的弱起阶段，常见上弓吸气后再落下弓进入主题，此时应优先考虑 phrase 的呼吸，而不是一味地“连奏保向”。

4. 换弦遵循实演惯性，不由“是否连奏”单独决定
   - 高音弦 → 低音弦更常见为上弓；
   - 低音弦 → 高音弦更常见为下弓；
   - 但如果明确存在 slur，可以在同一弓向内继续完成跨弦过渡。

5. 过长同向段必须打断
   - 若同一方向出现了多个短音连续同向，且不属于真实 slur 段，则需要插入换向点。
   - 目的是避免弓位在弓根或弓尖附近堆积，造成机械臂动作卡顿。

6. 机械臂保弓位上限/下限
   - 当弓位接近端点时，触发重置或反向补偿，避免机械臂在极端位置反复卡住。

## 2. 当前版本中 slur 的真实状态

需要明确说明：

- 当前代码中存在 slur / legato 的接口，但它并不是来自视觉识谱模块的真实输出。
- 目前真正能用到的仍然是：
  - 显式输入的 slur 标记；
  - MIDI 隐式检测（同弦、短时间差、短音程）。
- 视觉识谱模块尚未对接，所以“谱面真实 slur”目前仍是预留接口，而不是已完成功能。

因此，当前规则不能把所有连续音符都当成“同一弓段”；只有满足以下条件时，才允许保向：
- 同弦或近弦；
- 时差在阈值内；
- 音程跨度在阈值内；
- 不是长延音；
- 不是明显 phrase 边界；
- 没有产生过长同向积压。

## 3. 决策层次（当前有效版本）

### 3.1 第一层：强弱拍与弱起呼吸

在没有强烈反例时，默认遵循：
- 强拍更容易落下弓；
- 弱拍/弱起更适合上弓吸气。

这条规则的意义在于：
- 它不代表“强拍一定下弓、弱拍一定上弓”是绝对真理；
- 它只是一个优先方向，用于在 phrase 边界、起句和收尾附近给出更自然的弓行。

因此，像曲首弱起的 B3 → D4 这样的起句，通常更自然的是：
- 第一音用上弓吸气；
- 第二音再落到下弓承接主题。

这比两音连续 down 更符合真实演奏的声线和呼吸。

### 3.2 第二层：长音/延长音换向边界

长音与延长音是最容易被误判的地方。

规则是：
- 若当前音或上一音为长延音，不再沿用上一方向；
- 需要在合理位置换向；
- 在换向前后，机械臂应尽量避免长时间保持同一方向。

这条规则的价值在于：
- 避免弓头被压在弓根或弓尖附近；
- 避免演奏中机械感过强；
- 更符合小提琴声部的自然起落。

### 3.3 第三层：slur 与 legato

当检测到 slur 或 legato 时：
- 若前后仍属于真实持续行程，则保留同一弓向；
- 若出现长音、换弦、弓位接近终点或 phrase 边界，则打断并换向。

注意：
- 连奏不等于“无限保向”；
- 连奏必须服从“时间长度、弓位余量、phrase 结构”三者的限制。

### 3.4 第四层：换弦换弓规则

换弦时优先按照真实小提琴惯性进行：
- 高弦 → 低弦：常用上弓；
- 低弦 → 高弦：常用下弓；
- 但如果当前字句中存在明确 slur，则可保持同一弓向继续。

这个规则的重点是：
- 它不是单纯的“看 pitch 差值”；
- 它是一种基于弦位与撥弓惯性的实际演奏经验。

### 3.5 第五层：过长同向段打断

当同一方向连续出现多个短音，而又不是真实的 slur 段时，需要打断：
- 尤其是同弦快速连续短音；
- 或者在 phrase 中出现明显“吸气—落下”的句法节奏时。

这个规则本质上对应你们反复指出的“呼吸感”问题：
- 不是所有相邻音都应保向；
- 真实演奏中更像“2–3 音为一呼吸段，再在边界处过渡”。

## 4. 当前版本的判定伪代码

```text
for each note in sequence:
    strong_beat = is_strong_beat(beat_position)

    if previous_note is None:
        if not strong_beat:
            direction = UP   # 弱起吸气
        else:
            direction = DOWN # 强拍落下
        is_legato = False
        continue

    if current_note is long_sustain or previous_note is long_sustain:
        direction = opposite(previous_direction)
        is_legato = False
        continue

    if explicit_slur is true:
        direction = previous_direction
        is_legato = True
    else if implicit_legato_detection and same_string_short_gap(note):
        direction = previous_direction
        is_legato = True
    else:
        if string change without slur:
            direction = practical_string_change_direction(note)
        else:
            direction = default_direction_by_beat(note, strong_beat)
        is_legato = False

    if same_direction_has_accumulated_too_long_without_real_slur:
        direction = opposite(direction)
        is_legato = False

    if bow_position_near_end:
        direction = opposite(direction)
        needs_reset_bow = False

    update previous_direction, previous_note, bow_position
    compute bow_speed
```

## 5. 关键修正点（本次说明的新增重点）

### 5.1 连奏不能和分弓冲突

如果一段音符被标记为 slur/legato，那么它们应尽可能保持同一弓向。

例如：
- 19 → 20 → 21 这组如果判定 legato，则不应出现 20 down / 21 up 这样的分弓。
- 若在音乐上要求此处反向，则应该去掉 legato 标记，或者将 phrase 切成两个独立弓段。

### 5.2 弱起与起句要考虑“吸气”

曲首或句首不应简单地从第一音就压“down”。

在真实演奏中，起句往往是：
- 先上弓吸气；
- 再落下弓进入主音/强拍。

这和“连音保向”是两回事，前者更关注 phrase 的起始呼吸。

### 5.3 过长同向会导致弓位积压

如果一段中有多个音都同向且不是真实 slur，那么会导致：
- 弓位在弓根/弓尖附近堆积；
- 后续换向时动作变得机械；
- 机械臂需要更大幅度的补偿和 reset。

因此，必须在短句边界处打断同向，以保证 phrase 的呼吸感和弓段平衡。

## 6. 对未来扩展的说明

未来如果接入视觉识谱模块，正确的扩展方式是：
- 把谱面 slur 区域直接写入显式连弓结构；
- 然后由 `BowDecisionEngine` 在 `explicit_legato` 阶段优先使用这些信息；
- 再在同弓/长音/弓位异常等条件下执行最终修正。

也就是说，视觉 slur 应该成为“高优先级输入”，而不是完全取代实演经验规则。

当前状态：
- 视觉识谱模块未接入；
- 算法仍然依赖 MIDI 隐式与经验规则；
- 但规则层已经围绕真实演奏行为做了修正，并且逻辑更贴近小提琴实战习惯。

---

## 7. 结论

当前版本的核心思路不是“只要连音就保向”，而是：
- 真实小提琴演奏中，方向决策必须服从 phrase、节奏、弓位和换弦惯性；
- 连奏只是其中一个因素，不是唯一因素；
- 长音、换弦、弱起、过长同向都必须有明确处理；
- 视觉 slur 接口留空，但当前经验规则已更接近真实演奏习惯。

这也正是近期针对梁祝的方向表被反复修正的根本原因：
- 真正现实的弓路，不是靠“同弦相邻音就保向”来构建；
- 而是靠“短句呼吸 + 长音换向 + 弓位限制 + 换弦惯性”共同决定。
- 这次修正的重要现实意义是：长音不再被误判为“同一弓段的延续”，因此程序更接近真实小提琴演奏中‘延长音要换向’的习惯。
- 该决策模块目前是“向前兼容”的：
  - 对于纯 MIDI 文件，它提供更智能的弓向决策；
  - 对于未来五线谱识别，它可以被配置为“只按显式连弓工作”；
  - 但即使显式连弓也会在长延音情形下被打断，防止弓向错误持久化。

---

## 7. 推荐后续优化点

- 在 `converter.py` 中增加 `ConvertedNote.explicit_legato` 字段，明确区分“显式连弓”与“隐式推断连奏”。
- 用 MIDI 解析器读出节拍信息，替代当前的 `start_seconds / seconds_per_quarter` 简化方式。
- 在本模块中加入 `bow_position` 估计输出，便于仿真和硬件同步。
- 在 ROS mock 和 Arduino ack 中打印 `bow_direction` + `legato` 结果，便于 end-to-end 验证。
