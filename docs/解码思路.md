# 曲谱编解码思路

## 如何让同一套机械控制逻辑，适配不同调的曲谱？

---

# 第一部分：统一调的问题

## 一、核心思路（先说结论）

不要直接用“绝对音名（C D E）”或“固定简谱（1 2 3）”控制机械臂，而是：

```text
统一用：
相对音级 + 调性映射 → 绝对音高 → 机械控制
```

---

## 二、三层表示体系

### ① 相对层（音乐语义层）

用首调唱名法（movable Do）

例如（《梁祝》某段）：

```text
1 2 3 5 6
```

这里的“1”不是 C，而是“主音（tonic）”

---

### ② 调性层（Key Mapping）

定义一个调：

```text
D大调 → 1 = D
G大调 → 1 = G
```

本质：

```text
scale_degree → absolute_pitch
```

---

### ③ 绝对层（机械执行层）

最终必须转成：

```text
音高（Hz or MIDI） → 弦 + 把位 → 舵机角度
```

---

## 三、推荐实现方法

### 引入 MIDI 编码（强烈推荐）

定义中间层：

```text
音符 → MIDI编号（0~127）
```

例如：

```text
C4 = 60
D4 = 62
```

调性转换公式：

```text
MIDI = tonic_MIDI + scale_offset
```

例如（D大调）：

```text
1 → D → 62
2 → E → 64
3 → F# → 66
```

代码示例：

```cpp
int scale_map_major[7] = {0, 2, 4, 5, 7, 9, 11};
int midi = tonic + scale_map_major[degree - 1];
```

---

## 四、两个关键问题

### 1. 升降号（非常关键）

例如：

```text
F#（升4）
Bb（降7）
```

必须支持：

```text
degree + accidental
```

编码建议：

```text
N3# （升3）
N7b （降7）
```

转换方式：

```cpp
midi = tonic + scale_offset + accidental;
```

其中：

```text
# → +1
b → -1
```

---

### 2. 转调（modulation）

《梁祝》一定会出现转调。

需要支持：

```text
KEY_CHANGE G_major
```

例如：

```text
KEY D
N1 N2 N3

KEY G
N1 N2 N3
```

这时候：

- 不改“旋律结构”
- 只改“映射规则”

---

## 五、机械系统如何适配调变化

### 1. 不要直接存“音名 → 舵机角度”

而是：

```text
MIDI → 弦选择 + 手指位置
```

---

### 2. 建立“指板模型”（推荐）

类似：

```text
弦（G D A E）
+ 半音位置（0~12）
```

例如：

```text
MIDI 69（A4）
→ A弦空弦
```

---

### 3. 优化策略（非常关键）

同一个音可以多个位置。

需要策略：

```text
选择最小运动距离
```

否则：

```text
手会乱跳
完全不可演奏
```

---

## 六、最终推荐系统结构

```text
曲谱（简谱/五线谱）
 ↓
相对音级表示（1~7 + 升降号）
 ↓
调性映射（Key → MIDI）
 ↓
音高标准化（MIDI）
 ↓
指板映射（弦 + 把位）
 ↓
舵机控制信号
```

---

## 七、工程上最优解

### 必做

- 相对音级（1~7）
- Key → MIDI 映射
- 基本升降号支持

### 进阶

- 转调支持
- 最小位移优化

### 高级

- 用反馈系统自动选择最佳指法

---

## 八、报告总结（可直接使用）

> 为解决不同调性曲谱的统一表达问题，系统采用基于首调唱名法的相对音级编码方式，并引入调性映射模块，将音级信息动态转换为标准化的 MIDI 音高。该方法实现了演奏逻辑与调性解耦，使机械系统能够在不改变控制结构的前提下适配不同调的乐曲，并为后续转调处理与智能指法优化提供了基础。

# 第二部分：编解码框架

## 一、总体架构

```text
曲谱（梁祝）
 ↓
① 音乐要素解析（Music Parsing）
 ↓
② 编码系统（Symbol Encoding）
 ↓
③ 控制映射（Motion Mapping）
 ↓
④ 执行层（Arduino + 舵机）
```

---

## 二、第一层：曲谱要素拆解

### 1. 左手（音高相关）

- 音符 pitch（A4、B4 或简谱 1~7）
- 把位 position
- 手指 finger
- 滑音 glissando
- 揉弦 vibrato

本质变量：

```text
Pitch → (弦选择 + 按弦位置)
```

---

### 2. 右手（弓法相关）

- 弓向（上弓 / 下弓）
- 弓速
- 弓压
- 接触点

本质变量：

```text
音量 / 音色 → (弓速 + 弓压 + 接触点)
```

---

### 3. 时间结构（节奏系统）

- 音符时值
- BPM
- 连音
- 断音

本质变量：

```text
时间轴调度
```

---

# 三、第二层：编码系统设计

建议升级为结构化编码语言。

---

## 1. 定义机器语言

格式：

```text
N[pitch][duration][bow][velocity][force]
```

例如：

```text
N5_8_D_6_4
```

解释：

```text
pitch = 5
duration = 八分音符
D = 下弓
velocity = 6
force = 4
```

---

## 2. 针对《梁祝》的优化

增加：

- S = 滑音
- V = 揉弦

例如：

```text
N3_4_U_5_3_S1_V0
```

---

# 四、第三层：控制映射

## 1. 左手映射

```text
Pitch → (弦, 手指位置) → 舵机角度
```

例如：

```text
5（简谱） → A弦2指 → servo_L = 35°
```

本质：

```text
lookup table（查表系统）
```

---

## 2. 右手映射

### （1）弓向

```text
U → 正方向运动
D → 反方向运动
```

### （2）弓速

```text
velocity → PWM / 速度控制
```

### （3）弓压

```text
force → 舵机压力 or 弹簧压缩量
```

---

## 3. 时间调度（关键）

必须实现：

```text
非阻塞式控制（millis 而不是 delay）
```

否则：

```text
无法实现连音 & 平滑控制
```

---

# 五、第四层：系统实现结构（Arduino）

## 1. Parser（解析器）

```cpp
struct Note {
    int pitch;
    int duration;
    char bow_dir;
    int velocity;
    int force;
};
```

---

## 2. Scheduler（调度器）

- 根据 BPM 转换时间
- 控制何时执行下一个音符

---

## 3. Motion Controller（运动控制）

- 左手舵机控制
- 右手弓控制（速度 + 力）

---

# 六、关键难点

## 1. 音符 → 动作不是一一对应

同一个音可以：

- 不同弦演奏
- 不同把位

需要：

```text
最小位移原则
```

---

## 2. 连音问题

- 弓不能停
- 左手提前准备

需要：

```text
前瞻控制（look-ahead）
```

---

## 3. 滑音实现

不是跳变，而是：

```text
连续轨迹控制（插值）
```

---

## 4. 力与音色的耦合

```text
音色 ≠ 单一变量
```

---

# 第三部分：流程示例

## “简谱 → MIDI → 机械指令”流程

---

## 一、《梁祝》示例片段

简谱（D大调）：

```text
1 2 3 5 | 3 2 1 -
```

节奏：

```text
4/4拍，每个音为四分音符
```

---

## 二、Step 1：简谱 → 相对音级结构

```text
[
(1, 1/4), (2, 1/4), (3, 1/4), (5, 1/4),
(3, 1/4), (2, 1/4), (1, 1/4), (rest, 1/4)
]
```

---

## 三、Step 2：调性映射（D大调）

```text
1=D, 2=E, 3=F#, 4=G, 5=A, 6=B, 7=C#
```

设：

```text
D4 = 62
```

对应：

| 简谱 | 音名 | MIDI |
|---|---|---|
| 1 | D4 | 62 |
| 2 | E4 | 64 |
| 3 | F#4 | 66 |
| 5 | A4 | 69 |

得到 MIDI 序列：

```text
[62, 64, 66, 69, 66, 64, 62, REST]
```

---

## 四、Step 3：MIDI → 小提琴指法映射

第一把位：

| MIDI | 音名 | 弦 | 手指 | 舵机角度 |
|---|---|---|---|---|
| 62 | D4 | D弦 | 0（空弦） | 0° |
| 64 | E4 | D弦 | 1 | 15° |
| 66 | F#4 | D弦 | 2 | 30° |
| 69 | A4 | A弦 | 0 | 0° |

得到机械参数：

```text
[
(D弦,0),
(D弦,1),
(D弦,2),
(A弦,0),
(D弦,2),
(D弦,1),
(D弦,0)
]
```

---

## 五、Step 4：加入弓控制

定义：

```text
全部下弓
速度 = 5
压力 = 4
```

# 九、Arduino端解析逻辑

int tonic = 62;

---

## 3. MIDI → 指法

```cpp
FingerMap mapNote(int midi) {
    // 查表 or 简单规则
}
```

---

## 4. 执行控制

```cpp
void playNote(Note n) {

    int midi = convertToMidi(n);

    Finger f = mapNote(midi);

    setLeftHand(f.string, f.finger);

    setBow(n.bow, n.velocity, n.force);

    wait(n.duration);
}
```
