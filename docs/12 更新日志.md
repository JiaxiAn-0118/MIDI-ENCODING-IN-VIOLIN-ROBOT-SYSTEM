## 2026-08-23 运弓决策前瞻改造与转换结果更新

- 人员信息：Jiaxi An

- 运弓决策器新增 `decide_all()` 批量入口，支持最多 2 个未来音符的有限前瞻窗口。
- 增加弱拍接强拍时的弱起上弓判断，以及休止前最后一个音的下弓准备判断。
- MIDI 转换流程切换为批量弓法决策，保留原有 `decide()` 接口以兼容单音符调用。
- 重新生成小星星、梁祝的 lookahead 版本 JSON 与 BIN 输出，并完成事件数量和 BIN 字节长度校验。
- 更新运弓方向决策说明文档，明确当前离线批量决策不需要双线程，长音完整弓位预规划仍属于后续优化。
- 新增实时双线程骨架模块 `streaming.py`：定义 `ViolinAction`、`NoteSource`、`ActionSink` 与 `RealtimePipeline`，并采用有界队列与结束哨兵机制。
- 明确实时线程边界为“决策后、执行前”：生产者按小节调用 `decide_all()` 入队动作，消费者仅负责出队执行，保证 `BowDecisionEngine` 状态由生产者线程独占。
- 新增《实时双线程骨架说明》文档，沉淀设计目标、线程安全约束、队列策略与后续接入步骤（视觉识谱输入与 ROS/Arduino 执行端）。
