# 小提琴机器人系统架构

---

## 系统数据流

```
┌─────────────────────────────────────────────┐
│           Sheet Music / MIDI                │
│         (简谱 / 五线谱 / MIDI文件)             │
└──────────────────┬──────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│              Music Parser                   │
│           (曲谱解析器，提取音符)                 │
│     输入: 原始曲谱   输出: 结构化音符序列          │
└──────────────────┬──────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│         Violin Event Generator              │
│        (小提琴演奏事件生成器)                    │
│  输入: 音符序列   输出: 演奏事件(音高/时值/弓法)    │
└──────────────────┬──────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│       String / Finger Assignment            │
│        (弦位 / 手指分配器)                     │
│   输入: 演奏事件   输出: 弦位 + 指法指令          │
└──────────────────┬──────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│            Motion Mapping                   │
│           (运动学映射，计算舵机角度)             │
│    输入: 弦位指令   输出: 舵机控制参数            │
└──────────────────┬──────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│           Servo Controller                  │
│         (舵机控制驱动，时间调度)                 │
│     输入: 角度参数   输出: PWM信号              │
└──────────────────┬──────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│            Violin Robot                     │
│          (物理执行层，实际演奏)                 │
│     输入: PWM信号   输出: 声音                 │
└─────────────────────────────────────────────┘
```

---

## 各层级详情

| 层级 | 模块名称 | 核心功能 | 输入 | 输出 |
|:----:|----------|----------|------|------|
| 1 | Sheet Music / MIDI | 曲谱或MIDI文件源 | 简谱/五线谱 | 原始音符数据 |
| 2 | Music Parser | 解析曲谱结构 | 原始曲谱 | 结构化音符序列 |
| 3 | Violin Event Generator | 生成演奏事件 | 音符序列 | 音高+时值+弓法 |
| 4 | String / Finger Assignment | 分配弦与手指 | 演奏事件 | 弦位+指法指令 |
| 5 | Motion Mapping | 运动学映射 | 弦位指令 | 舵机角度参数 |
| 6 | Servo Controller | 舵机驱动 | 角度参数 | PWM信号 |
| 7 | Violin Robot | 物理执行 | PWM信号 | 声音输出 |

## 软件系统架构设计

系统架构由 **数据编译**、**运动仿真**、**实时通信**、**嵌入式执行** 以及 **智能化远期扩展** 五大核心层级构成，形成了完整的软硬件闭环体系。

```text
 ┌────────────────────────────────────────────────────────────────────────┐
 │                         离线编译与工具链层                                 │
 │   • MIDI / 曲谱解析 (Python CLI)  ──► 提取演奏事件 ──► 12字节二进制编码        │
 └───────────────────┬────────────────────────────────┬───────────────────┘
                     │                                │
                     ▼                                ▼
 ┌───────────────────────────────┐┌────────────────────────────────────────┐
 │        离线仿真与验证层           ││             在线通信与控制层              │
 │   • MATLAB 机械/运弓动力学仿真    ││   • ROS2 节点 (曲谱播放/调度)             │
 │   • 逆运动学与轨迹规划算法验证      ││   • Serial Bridge (与 GIGA 高速串口桥接)  │
 └───────────────────────────────┘└───────────────────┬────────────────────┘
                                                      │
                                                      ▼
                                  ┌───────────────────────────────────────┐
                                  │           嵌入式硬件执行层               │
                                  │   • Arduino GIGA R1 / 嵌入式固件        │
                                  │   • 实时事件解码与电机驱动控制              │
                                  └───────────────────────────────────────┘
```

### 1. 数据处理与数据编译层 (`violin_midi_json`)
* **定位**：前级数据转换与曲谱编译器。
* **功能实现**：
  * **格式解析**：提取 MIDI 文件中的音高、时值、节拍与控制事件，生成便于调试与可视化展示的 JSON 格式文件。
  * **二进制压缩**：将小提琴演奏动作打包为自定义二进制文件（`.bin`）。每个演奏事件精简至 **12 字节**（例如：《小星星完整版》共 35 个事件，总数据量精确控制在 420 字节），大幅降低嵌入式端的内存开销与通信带宽要求。

### 2. 离线仿真与算法验证层 (`simulation`)
* **定位**：动力学建模与运弓轨迹规划验证平台。
* **功能实现**：
  * 基于 MATLAB 搭建小提琴机器人按弦与运弓的机械动力学及运动学模型。
  * 用于离线校验弓速、弓压、持弓姿态及逆运动学求解，在物理硬件调试前完成运动算法的理论验证。

### 3. 上位机控制与通信中枢层 (`ros2_ws`)
* **定位**：实时/半实时分布式机器人操作系统中枢。
* **功能实现**：
  * **曲谱调度与播放**：基于 ROS2 架构设计曲谱播放节点，实现离线二进制数据的按时轴读取与调度。
  * **串口桥接与传输**：开发 ROS2-GIGA 串口桥接模块（`giga_serial_bridge`），保障上位机与下位机之间的高速率、低延迟指令交互。

### 4. 嵌入式固件与硬件执行层 (`firmware/arduino/`)
* **定位**：底层实时执行与控制固件。
* **功能实现**：
  * **脱机单机测试 (`test1`)**：支持将编译好的二进制曲谱直接转存为头文件 (`.h`) 静态烧录，用于单片机最小系统（MVT）的基础动作脱机验证。
  * **在线桥接控制 (`giga_serial_bridge`)**：部署于 Arduino GIGA R1 主控板，负责动态接收并解码 ROS2 传输的二进制字节流，直接驱动底层电机执行机构。

### 5. 智能化闭环扩展预留 (`docs/智能化优化方案.md`)
* **定位**：远期算法演进与高级控制框架。
* **规划路线**：
  * **自动弓法生成**：由简单的 MIDI 音符映射升级为结合表现力的运弓规划（上/下弓、连弓等）。
  * **声音质量评估**：结合音频采集与声学分析，构建“听觉-控制”实时反馈闭环。
  * **数字孪生与自动校准**：通过仿真模型与真实物理反馈联动，实现机械零位校准与动态参数自适应。
