# 小提琴机器人系统架构图

## 系统数据流

```
┌─────────────────────────────────────────────┐
│           Sheet Music / MIDI                │
│         (简谱 / 五线谱 / MIDI文件)            │
└──────────────────┬──────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│              Music Parser                   │
│           (曲谱解析器，提取音符)               │
│     输入: 原始曲谱   输出: 结构化音符序列        │
└──────────────────┬──────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│         Violin Event Generator              │
│        (小提琴演奏事件生成器)                  │
│  输入: 音符序列   输出: 演奏事件(音高/时值/弓法)  │
└──────────────────┬──────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│       String / Finger Assignment            │
│        (弦位 / 手指分配器)                    │
│   输入: 演奏事件   输出: 弦位 + 指法指令         │
└──────────────────┬──────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│            Motion Mapping                   │
│           (运动学映射，计算舵机角度)            │
│    输入: 弦位指令   输出: 舵机控制参数           │
└──────────────────┬──────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│           Servo Controller                  │
│         (舵机控制驱动，时间调度)                │
│     输入: 角度参数   输出: PWM信号              │
└──────────────────┬──────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│            Violin Robot                     │
│          (物理执行层，实际演奏)                │
│     输入: PWM信号   输出: 声音                 │
└─────────────────────────────────────────────┘
```

## 各层级详情

| 层级 | 模块名称 | 核心功能 | 输入 | 输出 |
|:----:|----------|----------|------|------|
| 1 | Sheet Music / MIDI | 曲谱或MIDI文件源 | 简谱/五线谱 | 原始音符数据 |
| 2 | Music Parser | 解析曲谱结构 | 原始曲谱 | 结构化音符序列 |
| 3 | Violin Event Generator | 生成演奏事件 | 音符序列 | 音高+时值+弓法 |
| 4 | String / Finger Assignment | 分配弦与手指 | 演奏事件 | 弦位+指法指令 |
| 5 | Motion Mapping | 运动学映射 | 弦位指令 | 舵机角度参数 |
| 6 | Servo Controller | 舵机驱动 | 角度参数 | PWM信号 |
| 7 | Violin Robot | 物理执行 | PWM信号 | 声音输出 |
